Install FrameCine

A free VR video player for the Steam Frame, cinema first: your films on a big screen in a real room, with spatial sound.

Install with Frame Control Install with FrameDrop

Both install from a PC: turn on Developer Mode on the headset (Steam Settings, System, Developer Mode) and pair it once with the installer. Each asks before it installs. FrameCine then shows in the Steam library under Non-Steam, and updates itself from then on.

By hand

Download framecine-…-arm64.zip from the latest release and drop it on Frame Control or FrameDrop. The install guide has every way, and how to remove it.
