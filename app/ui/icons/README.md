# Icons

Original line icons in the spirit of traditional audio-visual equipment (a CRT face, a VU meter, a rack unit,
the back row of a cinema, a lava lamp), drawn for this app; MIT with the rest of it. `viewBox 0 0 24 24`,
strokes in `currentColor` at 1.75 (the transport keys at 2), round caps and joins, everything inside 2..22.
Colour only where it means something: the colour bars on `picture.svg`, the red zone past 0 dB on
`sound.svg`, the yellow captions on `subtitles.svg`, the warm wax in `objects.svg`, the standby lamp on
`system.svg`, the camera's lens on `mixed-reality.svg` (an old stereo viewer: one eye on the real room). The rest takes the colour it is drawn with (ui/icons.gd).
