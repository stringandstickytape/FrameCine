# Languages (i18n)

The menus and the controller labels can show in another language. English is the default. Simplified Chinese is the
first other language. It is a machine draft: no native reader has checked it yet.

## How it works

- Godot's TranslationServer does the work. Each language is one gettext file in `app/locale`, such as `zh_CN.po`.
- The key is the English text itself (gettext style). `app/locale/messages.pot` lists every key.
- `app/scripts/i18n.gd` loads the files at start, before the menus are built. It is called from `main.gd`
  `_ready()`.
- The language is the setting `[language] ui` in `user://settings.cfg`. No value means English.
- The app never reads the OS locale. The headset starts the app with `LC_ALL=C` or with no locale.
- The System tab has a Language section. Each language shows its name in its own language: English, 简体中文.
- A change applies at once. No restart.

## The three rules

1. **Fixed words.** Give the control the English: `W.label("Room")`, `W.button("Play", ...)`, `b.text = "Pause"`.
   The control translates its own text (Godot's auto-translate). It does so again when the language changes.
2. **Built text.** Text with a number or a name in it goes through `tr()` as a whole sentence, with placeholders:
   `tr("Delete %s from the library?") % name`. Never glue fragments: not `tr("Delete") + " " + name`. For a count,
   use `tr_n()`: `tr_n("%d item", "%d items", n) % n`. Chinese has one form; English has two.
   Build the text again when the language changes (see "Live switching").
3. **Content.** Film titles, file and folder names, host names, seat and object names, and what the viewer typed
   are never translated. Put them on a control marked with `W.content(control)`. That turns auto-translate off,
   so a folder called "Room" stays "Room" in Chinese. Never pass content through `tr()`.

Text that the code translated itself can also go on a `W.content()` control. That is what the header, the footer,
the toasts, the tablet's labels, the hand hint and the world notice do.

These calls show text as given, so the caller translates: `ui.show_toast(tr("Saved"), tr("Undo"), ...)`,
`show_choice()`, `set_status()`, `ui_layer.notify()`, `world_toast.show_text()`, `hand_hint.show_over()`.

In static functions there is no `tr()`. Use `TranslationServer.translate("...")` and
`TranslationServer.translate_plural("...", "...", n)`.

Keep the English exactly as it is. It is written in a deliberate plain style, and it is the key.

### Live switching

- Fixed words switch by themselves.
- `I18n.holder().changed` is emitted after a switch. `pane_ui.gd` then calls `sync()` on every tab that has one,
  and `tick()`. So built text that a tab sets in `sync()` or `tick()` switches too.
- For a label built once, use `W.live_label(func() -> String: return tr("Engine %s, %s") % [a, b])`. It is built
  again on each switch.
- A node can also handle `NOTIFICATION_TRANSLATION_CHANGED` (see `ui/hw_video_row.gd`).
- `main.gd` prints the controller legends again on a switch.

### Lists of words in constants

The extraction (below) cannot see a word that reaches a control through a variable. Mark the source:

- `# i18n` at the end of a line: every string on the line is a key, except dictionary keys.
- `# i18n: begin` ... `# i18n: end` around a block: the same for every line in it.
- `# i18n: begin name`: only the values of `"name": ...` in the block (for tables of presets).

Examples: `TABLET_TAB_NAMES` in `ui/pane_ui.gd`, `CONTROL_LABELS` in `scripts/main.gd`, `LOOKS` in
`scripts/xr/controller_look.gd`, the help lines in `ui/help_texts.gd`. Keep ids and settings values off marked
lines: they would become keys.

## Not translated

- The dev link and the assistant: command names, the registry's descriptions, results and errors
  (`app/scripts/dev/*_commands.gd`, `app/scripts/assistant/`). An assistant reads them in English.
- Log lines, `print()`, `push_error()`.
- Settings keys and values, file names, ids.
- The docs.
- Functions that both the menus and an assistant use stay English by default. They take a `localised` flag for the
  menu (`EndTime.format_end()`, `format_remaining()`, `features.end_text()`).

## Extraction

`tools/i18n.py` (Python 3, no packages) does it. Run it from the repository root:

    python3 tools/i18n.py extract            # every key in app/ -> app/locale/messages.pot
    python3 tools/i18n.py check              # keys missing from each .po, keys a .po has that the template does not
    python3 tools/i18n.py merge app/locale/zh_CN.po   # adds the new keys (empty) and moves old ones to the end

What counts as a key: `tr()`, `tr_n()`, `atr()`, `TranslationServer.translate()` and `translate_plural()` with a
string; the text of a `W` builder (`label`, `caps`, `section`, `button`, `toggle`, `help`, `slider_row`, and every
string of `choices([...])`) when it is a string; a string given to `text`, `tooltip_text` or `placeholder_text`
(also `"A" if c else "B"`); the markers above; the palette names in `ui/themes/tablet.json`. Text with no letter is
never a key. `app/tests` and `app/tools` are not read. In `app/scripts/dev` and `app/scripts/assistant` only
`tr()` and the markers count.

Run `extract` after a change to the menus' text, then `check`. `check` exits 1 when a key is missing.

## Add a language

1. Copy `app/locale/zh_CN.po` to `app/locale/<code>.po` (for example `de.po`). Set its header: `Language:` and
   `Plural-Forms:` (German: `nplurals=2; plural=(n != 1);`).
2. Empty the `msgstr` lines, or start from `messages.pot`, and translate. `merge` keeps it up to date.
3. Add `["de", "Deutsch"]` to `LANGUAGES` in `app/scripts/i18n.gd`.
4. A script that Fira Sans has no glyphs for needs a font. See "Fonts".
5. Run `check`, and `app/tests/test_i18n.gd`.

Godot's loader skips entries marked `#, fuzzy`. Do not mark a draft fuzzy if it should show.

## The pseudo-locale

A check for text that is not wrapped. Every key of `messages.pot` is shown accented, about a third longer, in
brackets: `[Šéţţîñĝš ~~~]`. It is made at run time from the template; there is no file for it. Text that stays plain
English is text the extraction does not know. Content stays plain on purpose.

It is offered in the System tab only in dev mode (`--dev`, or a listener). `--pseudo-locale` starts the app in it.
It is never saved: the next start is in the saved language.

## Fonts

- The menu's font is Fira Sans Condensed. It has no CJK glyphs.
- `app/ui/fonts/NotoSansSC-Medium-subset.woff2` is the Simplified Chinese fallback (SIL OFL 1.1,
  `app/ui/fonts/LICENSE.NotoSansSC.txt`). It is a subset of Noto Sans SC Medium from
  github.com/notofonts/noto-cjk (`Sans/SubsetOTF/SC`). It has the 3755 common characters of GB 2312 level 1,
  every character of the .po files, and CJK punctuation. It is 0.65 MB.
- `tools/i18n.py font --source NotoSansSC-Medium.otf` makes it again (needs `pip install fonttools brotli`). Run it
  after new translations, so their characters are in it. `test_i18n.gd` checks that they are.
- The subset takes Fira's line height. Godot sizes a button by the tallest font of the chain, so Noto's own taller
  line made every menu row grow, in English too.
- `I18n.add_font_fallbacks()` puts the font behind Fira's four FontFiles at start. Every theme font, the tablet's
  Label3Ds, the hand hint and the world notice use them, so this one place covers them all.
- Chinese wraps between characters (the TextServer's line breaking). No spaces are needed.
- Film titles and subtitles in Chinese are content. Characters outside the subset fall back to the system's fonts,
  if it has any.

## Controller labels

- The legends are drawn from one atlas of distance fields (`app/scripts/xr/label_font.gd`). The Chinese font is the
  fallback there too, as distance fields.
- A CJK glyph takes about 60 px of the atlas, so the 512 px atlas holds only some 60 of them. When it is full it
  doubles, up to 2048 px: room for about 500 CJK glyphs. All the legends in one language use a few dozen.
- The glyphs already in the atlas keep their place. The quads' UVs are fractions of 2048 (`ATLAS_SPAN`), and the
  shader scales them to the atlas's size. So legends laid before a growth stay right.
- A Latin-only legend set never grows the atlas.
- A legend wider than its room is printed smaller (`label_layout.gd fitted_line()`). Longer translations fit that way.
- The legends are keys too (`CONTROL_LABELS`, `WINDOW_LABELS`, `TERMINAL_LABELS` in `main.gd`). Keep them short.
